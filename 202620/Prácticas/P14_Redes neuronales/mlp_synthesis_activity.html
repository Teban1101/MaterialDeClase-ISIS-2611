Ejercicio 1 — Modelo base (baseline)

Clasificación de 10 dígitos con un MLP

Sobre el dataset. MNIST contiene 70.000 imágenes en escala de grises de 28×28 píxeles, cada una con un dígito manuscrito del 0 al 9. Viene ya dividido en 60.000 imágenes de entrenamiento y 10.000 de prueba. Es el problema clásico para introducir clasificación multiclase con redes neuronales.

Meta. Construye y entrena un perceptrón multicapa que reciba cada imagen aplanada (784 valores) y prediga uno de los 10 dígitos. Elige libremente las capas ocultas y la función de activación, y reporta tu accuracy de prueba.

Pasos

1
Carga MNIST
Obtén los conjuntos de entrenamiento y prueba ya separados, y visualiza algunas imágenes para reconocer los datos.
2
Normaliza y aplana las imágenes
Lleva los valores de píxel al rango [0, 1] y convierte cada imagen 28×28 en un vector que el MLP pueda recibir.
3
Define la arquitectura del MLP
Arma un modelo secuencial con una o más capas ocultas densas y una capa de salida de 10 neuronas con softmax. Anota tu elección y por qué.
4
Compila y entrena
Configura optimizador, función de pérdida y métrica; entrena reservando una fracción de validación.
5
Evalúa el desempeño
Reporta accuracy de prueba, matriz de confusión y las curvas de accuracy/pérdida del entrenamiento. Inspecciona visualmente algunos aciertos y errores.

Entregable

Un notebook con la arquitectura elegida y su justificación, las curvas de entrenamiento, el reporte de clasificación, la matriz de confusión y una muestra de dígitos con sus predicciones.

Ejercicio 2 — Modelo optimizado

Regularización y callbacks

Punto de partida. Reutiliza el mismo MNIST y parte del modelo base del Ejercicio 1. El objetivo ya no es solo subir el accuracy de entrenamiento, sino lograr que el modelo generalice mejor a las imágenes de prueba y evitar que memorice el entrenamiento.

Meta. Entrena un modelo mejorado aplicando al menos un mecanismo de regularización y al menos un callback de entrenamiento, y compáralo cuantitativamente contra el modelo base.

Pasos

1
Agrega regularización
Incorpora capas de Dropout (y opcionalmente penalización L2) a tu arquitectura para reducir el sobreajuste. Puedes hacer la red más profunda.
2
Activa early stopping
Detén el entrenamiento cuando la pérdida de validación deje de mejorar; así puedes permitir más épocas sin riesgo.
3
Guarda el mejor modelo
Usa un checkpoint para conservar automáticamente los pesos de la mejor época según la validación.
4
Compara y concluye

La tabla comparativa train/test de ambos modelos, las curvas de entrenamiento lado a lado, la justificación de los mecanismos elegidos y una conclusión sobre la generalización.

Glosario Dataset MNIST

Dataset MNIST

Datos

MNIST es un conjunto de 70.000 imágenes en escala de grises de 28×28 píxeles, cada una con un dígito manuscrito (0–9). Keras lo incluye y lo entrega ya dividido en entrenamiento (60.000) y prueba (10.000), por lo que no necesitas hacer la partición manualmente.

python
from tensorflow import keras
import matplotlib.pyplot as plt

(X_train, y_train), (X_test, y_test) = keras.datasets.mnist.load_data()

print(X_train.shape)   # (60000, 28, 28)
print(y_train[0])      # etiqueta: un entero 0-9

plt.imshow(X_train[0], cmap='gray'); plt.show()
ElementoForma / tipo
X (imágenes)Arreglo (n, 28, 28), valores 0–255
y (etiquetas)Enteros 0–9, una clase por imagen
Clases10 (multiclase)
Glosario Normalizar y aplanar

Normalizar y aplanar

Preprocesamiento

Normalizar. Los píxeles vienen en el rango 0–255. Las redes entrenadas con descenso de gradiente convergen mejor cuando las entradas son pequeñas y de magnitud comparable, así que se dividen entre 255 para llevarlas a [0, 1]. Es el equivalente, en imágenes, a escalar las features.

Aplanar. Un MLP recibe vectores, no matrices 2D. Cada imagen de 28×28 se convierte en un vector de 784 valores. En Keras esto se hace cómodamente con una capa Flatten dentro del propio modelo.

python
# normalización 0-255 -> 0-1
X_train = X_train.astype('float32') / 255.0
X_test  = X_test.astype('float32') / 255.0

# el aplanado se hace en la arquitectura:
# layers.Flatten(input_shape=(28, 28))  ->  vector de 784
Nota: las etiquetas (0–9) pueden quedarse como enteros si usas la pérdida sparse_categorical_crossentropy. Solo necesitas one-hot si usas categorical_crossentropy.
Glosario keras.Sequential

keras.Sequential

Arquitectura del MLP

Un modelo secuencial apila capas una tras otra. Para un MLP sobre imágenes: una capa Flatten de entrada, una o más capas Dense ocultas con activación ReLU, y una capa Dense final con tantas neuronas como clases y activación softmax (que produce una distribución de probabilidad sobre las 10 clases).

python
from tensorflow.keras import Sequential, layers

model = Sequential([
    layers.Flatten(input_shape=(28, 28)),   # entrada: 784
    layers.Dense(128, activation='relu'),       # capa oculta
    layers.Dense(10, activation='softmax')       # salida: 10 clases
])
model.summary()
CapaFunción
FlattenConvierte la imagen 28×28 en un vector de 784
Dense(n, relu)Capa oculta; más neuronas/capas = más capacidad
Dense(10, softmax)Salida multiclase: probabilidad por dígito
Glosario compile y fit

compile y fit

Entrenamiento

compile configura cómo aprende el modelo: el optimizador (cómo actualiza los pesos), la función de pérdida (qué minimiza) y las métricas a monitorear. fit ejecuta el entrenamiento durante un número de épocas, y con validation_split aparta parte del entrenamiento para vigilar la generalización época a época.

python
model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.001),
    loss='sparse_categorical_crossentropy',   # etiquetas enteras
    metrics=['accuracy']
)

history = model.fit(
    X_train, y_train,
    epochs=15,
    batch_size=128,
    validation_split=0.2     # 20% del train para validación
)
ParámetroRol
optimizerAdam es una elección robusta por defecto
losssparse_categorical_crossentropy para etiquetas enteras multiclase
epochsPasadas completas sobre el entrenamiento
batch_sizeMuestras por actualización de pesos
validation_splitFracción del train reservada para validación
El objeto history guarda accuracy y pérdida de train y validación por época — la base para graficar las curvas de entrenamiento.
Glosario Evaluación

Evaluación del modelo

Métricas

Tres ángulos complementarios: evaluate da el accuracy sobre el conjunto de prueba; classification_report y confusion_matrix detallan el desempeño por dígito; y las curvas del objeto history muestran si hubo sobreajuste durante el entrenamiento.

python
import numpy as np, seaborn as sns, matplotlib.pyplot as plt
from sklearn.metrics import classification_report, confusion_matrix

loss, acc = model.evaluate(X_test, y_test)
print(f"Accuracy de prueba: {acc:.4f}")

y_pred = np.argmax(model.predict(X_test), axis=1)
print(classification_report(y_test, y_pred))

cm = confusion_matrix(y_test, y_pred)
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues'); plt.show()
python · curvas de entrenamiento
plt.plot(history.history['accuracy'], label='train')
plt.plot(history.history['val_accuracy'], label='validación')
plt.xlabel('Época'); plt.legend(); plt.show()
Si el accuracy de train sube pero el de validación se estanca o baja, hay sobreajuste — justamente lo que se ataca en el Ejercicio 2.
Glosario Visualizar predicciones

Visualizar predicciones

Inspección cualitativa

En problemas de imágenes conviene mirar ejemplos concretos: graficar varios dígitos junto a la clase predicha y la real ayuda a entender dónde falla el modelo (por ejemplo, confundir 4 con 9). Es el análogo, en MNIST, de graficar una frontera de decisión en 2D.

python
import numpy as np, matplotlib.pyplot as plt

y_pred = np.argmax(model.predict(X_test), axis=1)

plt.figure(figsize=(10, 4))
for i in range(10):
    plt.subplot(2, 5, i + 1)
    plt.imshow(X_test[i], cmap='gray')
    plt.title(f"pred {y_pred[i]} / real {y_test[i]}")
    plt.axis('off')
plt.show()
Tip: filtra solo los casos mal clasificados (y_pred != y_test) para inspeccionar los errores más reveladores.
Glosario Dropout y L2

Dropout y regularización L2

Control de sobreajuste

Dropout apaga aleatoriamente una fracción de las neuronas en cada paso de entrenamiento, obligando a la red a no depender de neuronas concretas y mejorando la generalización. Se inserta como una capa entre capas densas.

Regularización L2 añade a la pérdida una penalización proporcional a la suma de los cuadrados de los pesos, desincentivando pesos grandes. Se aplica por capa con kernel_regularizer.

python
from tensorflow.keras import Sequential, layers, regularizers

model = Sequential([
    layers.Flatten(input_shape=(28, 28)),
    layers.Dropout(0.3),                       # apaga 30% de entradas
    layers.Dense(256, activation='relu',
                 kernel_regularizer=regularizers.l2(1e-4)),
    layers.Dropout(0.2),
    layers.Dense(128, activation='relu'),
    layers.Dense(10, activation='softmax')
])
MecanismoEfecto
Dropout(p)Apaga una fracción p de neuronas; valores típicos 0.2–0.5
l2(λ)Penaliza pesos grandes; λ típico 1e-4 a 1e-2
Glosario EarlyStopping

EarlyStopping

Callback de entrenamiento

Detiene el entrenamiento automáticamente cuando la métrica de validación deja de mejorar durante varias épocas seguidas. Permite poner un número alto de épocas sin arriesgarse a sobreajustar: el entrenamiento para solo cuando ya no aporta.

python
from tensorflow.keras import callbacks

early = callbacks.EarlyStopping(
    monitor='val_loss',        # qué vigila
    patience=5,                 # épocas sin mejora antes de parar
    restore_best_weights=True   # vuelve a la mejor época
)

history = model.fit(
    X_train, y_train, epochs=30, batch_size=64,
    validation_split=0.2, callbacks=[early]
)
La validación se toma del entrenamiento (validation_split), no del conjunto de prueba, que se reserva para la evaluación final.
Glosario ModelCheckpoint

ModelCheckpoint

Callback de entrenamiento

Guarda automáticamente el modelo en disco durante el entrenamiento. Con save_best_only=True conserva únicamente la versión de la mejor época según la métrica vigilada, de modo que al final tienes los mejores pesos aunque épocas posteriores empeoren.

python
from tensorflow.keras import callbacks

checkpoint = callbacks.ModelCheckpoint(
    'best_mlp_model.keras',
    monitor='val_accuracy',
    save_best_only=True
)

history = model.fit(
    X_train, y_train, epochs=30, batch_size=64,
    validation_split=0.2, callbacks=[early, checkpoint]
)

# recuperar el mejor modelo guardado
best = keras.models.load_model('best_mlp_model.keras')
ArgumentoRol
monitorMétrica que decide cuál época es "la mejor"
save_best_onlySolo sobrescribe si la métrica mejora
